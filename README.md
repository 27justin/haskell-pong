# Controls

| Key                       | Action                    |
|---------------------------|---------------------------|
| <kbd>W/S</kbd>            | Controls the left paddle  |
| <kbd>Up/Down Arrows</kbd> | Controls the right paddle |
| <kbd>Space</kbd>          | Pause the game            |
| <kbd>Esc</kbd>            | Exit                      |
